<Warning>
  **Video-based avatar creation is no longer supported.** `POST /avatars` with `type: "VIDEO"` is rejected. The API returns `400` with the message `Video-based avatars are no longer supported. Use type: "IMAGE".`
</Warning>

Do not upload a dataset video or a consent video. There is no 1–5 minute training clip to send.

Create the avatar from one photo instead: [image-based avatar creation](/api-reference/endpoint/avatars.create).
